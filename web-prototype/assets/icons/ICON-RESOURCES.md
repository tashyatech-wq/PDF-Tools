# PDF Tools — Icon Resources

The app icon is a product-specific PDF document mark using the Tashya Labs
palette. It is intentionally different from the Tashya Labs company logo.

Included app icon resources:

- `app-icon-source.svg` — editable source icon
- `favicon.ico` — browser favicon
- `favicon-16.png` — 16 px favicon
- `favicon-32.png` — 32 px favicon
- `app-icon-64.png` — small app icon
- `app-icon-128.png` — small app icon
- `app-icon-256.png` — medium app icon
- `app-icon-512.png` — store/PWA base icon
- `apple-touch-icon.png` — iOS web clip icon

Company branding used inside the app:

- `../brand/tashya-labs-mark.png`
- `../brand/tashya-labs-logo-horizontal.png`

For native Android/iOS packaging, generate platform-specific icon sizes from
`app-icon-source.svg` or `app-icon-512.png`. Use the Tashya Labs logo only for
publisher/brand attribution such as "by Tashya Labs", not as the app icon.
